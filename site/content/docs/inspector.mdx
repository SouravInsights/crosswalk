---
title: Inspector
description: The in-page overlay for browsing and invoking your tools while authoring.
---

`@groundstate/inspector` is a small dev overlay that lives inside your page: every registered
tool, with a runner to invoke it and see live results. Use it while authoring
`observe` / `act` / `fixture` calls, and to debug why an agent run didn't behave as expected.

## Usage

```ts
if (import.meta.env.DEV) {
  groundstate.init({ appName: "my-app" });
  // ...registrations...
  import("@groundstate/inspector").then(({ mountInspector }) => mountInspector());
}
```

A "GS" button appears in the corner; click it to open the panel:

- every registered tool, with description and a **read**/**mutate** badge
- a JSON arguments editor and Run button per tool
- pretty-printed live results, including error passthrough

It renders in a shadow root, so it never collides with your app's styles.

## Options

```ts
mountInspector({ position: "bottom-left", open: true });
```

| Option | Default | Meaning |
|---|---|---|
| `position` | `"bottom-right"` | Corner for the toggle button |
| `open` | `false` | Start with the panel open |

`mountInspector()` returns `{ unmount }`.
